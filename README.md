# Stopwatch App ⏱️

## 📌 Description

A simple and responsive Stopwatch App built using HTML, CSS, and JavaScript with Start, Stop, and Reset functionality.

## 🎯 Purpose

The purpose of this project is to practice JavaScript functions, variables, conditional statements, and timer functions by creating an interactive stopwatch.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ✨ Features

- Start the stopwatch
- Stop the stopwatch
- Reset the timer to zero
- Display hours, minutes, and seconds
- Responsive and user-friendly design

## 🚀 How to Run

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.
4. Click **Start** to begin timing.
5. Click **Stop** to pause the timer.
6. Click **Reset** to return the timer to zero.
